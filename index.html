Teacher અહીંથી notification મોકલી શકે છે. Firebaseમાં notification record સાચવાશે અને વિદ્યાર્થી એપ ખોલે/foregroundમાં આવે ત્યારે બતાવાશે. OneSignal Push ON હોય તો notification OneSignal દ્વારા મોકલાશે.

🔔 OneSignal Push

OneSignal App ID APKમાં OneSignal integration સાથે match હોવો જોઈએ. REST/API Key HTMLમાં ન નાખશો. Secure Push URL મારફતે PDF/Photo Google Driveમાં પણ સેવ કરી શકાય છે.

☁️ Firebase Cloud Setup

✅ NIRMLA STUDY ZON Firebase Project 3: study-zon
આ એપમાં Firebase configuration પહેલેથી સેટ છે.

Project 3 ની Firebase Web App configuration અહીં એક વખત નાખો. ત્યારબાદ Students, Notices, Lessons અને પ્રશ્ન બેંકની માહિતી બધા devices પર cloudમાં sync થઈ શકશે.

💾 Backup & Restore

Appના Students, Notices, Lessons, Tests, Personal Messages અને પ્રશ્ન બેંકનો backup મોબાઇલમાં JSON તરીકે અથવા Google Cloud (Firebase)માં સાચવી શકાય છે.

☁️ Google Cloud Backup

Cloud Backup તમારા હાલના Firebase Realtime Database Project study-zonમાં cloudBackups/latest તરીકે સાચવશે.

⏱️ Google Cloud Backup તૈયાર છે. Backup/Restore માટે Internet જરૂરી છે.

નોંધ: PDF/Photoની actual file જો Firebase Storage અથવા Google Driveમાં હોય તો backupમાં તેનો URL/record સાચવાશે; મોટી binary file JSONમાં copy થતી નથી.
