📱 Student OTP Login
Student Registration અને Login માટે એપમાં જ 4 અંકનો Free OTP દેખાશે. SMSની જરૂર નથી.

⚙️ Teacher Login ID / Password

Login થયા પછી જ અહીંથી ID અને Password બદલી શકાશે.

👆 Teacher Fingerprint Login

આ Android appમાં ફોનનું Fingerprint / supported biometric lock વાપરી શકાય છે. પહેલાં Password Login કરો, પછી Setup કરો.

☁️ Firebase Cloud Setup

✅ NIRMLA STUDY ZON Firebase Project 3: study-zon
આ એપમાં Firebase configuration પહેલેથી સેટ છે.

Project 3 ની Firebase Web App configuration અહીં એક વખત નાખો. ત્યારબાદ Students, Notices, Lessons અને PDF Papers બધા devices પર cloudમાં sync થઈ શકશે.

💾 Backup & Restore

Appના Students, Notices, Lessons, વિષયવાર પ્રશ્નો અને Test PDFની માહિતીનો backup તમારા મોબાઇલમાં JSON ફાઇલ તરીકે સાચવી શકાય છે. જરૂર પડે ત્યારે એ જ ફાઇલથી Restore કરી શકાય છે.

નોંધ: PDF Offline Save માટે PDF download browser દ્વારા મંજૂર હોવું જરૂરી છે. Firebase Storage પરથી મળેલી PDF સામાન્ય રીતે સારી રીતે cache થઈ શકે છે.
