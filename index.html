📨 મોકલેલા Personal Messages

📱 Student OTP Login
Student Registration અને Login માટે એપમાં જ 4 અંકનો Free OTP દેખાશે. SMSની જરૂર નથી.

⚙️ Teacher Login ID / Password

Login થયા પછી જ અહીંથી ID અને Password બદલી શકાશે.

🖐️ Teacher Fingerprint / Face

Teacher માટે ફોનનું Fingerprint અથવા Face Unlock વાપરી શકાય છે. Student Login પર તેનો કોઈ અસર નહીં થાય.

🔔 Notifications

Teacher અહીંથી notification મોકલી શકે છે. Firebaseમાં notification record સાચવાશે અને વિદ્યાર્થી એપ ખોલે/foregroundમાં આવે ત્યારે બતાવાશે. એપ સંપૂર્ણ બંધ હોય ત્યારે સાચી push notification માટે Android APKમાં FCM native integration જરૂરી રહેશે.

☁️ Firebase Cloud Setup

✅ NIRMLA STUDY ZON Firebase Project 3: study-zon
આ એપમાં Firebase configuration પહેલેથી સેટ છે.

Project 3 ની Firebase Web App configuration અહીં એક વખત નાખો. ત્યારબાદ Students, Notices, Lessons અને પ્રશ્ન બેંકની માહિતી બધા devices પર cloudમાં sync થઈ શકશે.

💾 Backup & Restore

Appના Students, Notices, Lessons અને વિષયવાર પ્રશ્નોની માહિતીનો backup તમારા મોબાઇલમાં JSON ફાઇલ તરીકે સાચવી શકાય છે. જરૂર પડે ત્યારે એ જ ફાઇલથી Restore કરી શકાય છે.

નોંધ: PDF Offline Save માટે PDF download browser દ્વારા મંજૂર હોવું જરૂરી છે. Firebase Storage પરથી મળેલી PDF સામાન્ય રીતે સારી રીતે cache થઈ શકે છે.
